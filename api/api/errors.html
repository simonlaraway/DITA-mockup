Errors

The API uses standard HTTP status codes and returns a JSON error body that explains what went wrong.

Error format

{
  "error": {
    "code": "validation_failed",
    "message": "microchip must be 9, 10 or 15 digits",
    "field": "microchip",
    "request_id": "req_7Hc2xK9"
  }
}

Include the request_id when you contact support.

StatusCodeMeaning
400invalid_requestThe request is malformed, for example invalid JSON.
401unauthorizedThe API key is missing, invalid or deleted.
403forbiddenThe key doesn't have the required scope, or your plan doesn't include write access.
404not_foundThe resource doesn't exist, or belongs to another shelter.
409conflictThe change conflicts with the current state, for example approving an application for an animal that's already adopted.
422validation_failedA field value is invalid. See field and message.
429rate_limitedToo many requests. Retry after the time in Retry-After.
500internal_errorSomething went wrong on our side. Retry with backoff.
