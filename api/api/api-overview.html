About the CorgiBase API

The CorgiBase REST API lets you read and update your shelter's data from your own code: sync adoptable animals to your website, feed a dashboard, or connect a partner system.

The API is organized around resources such as animals, kennels, intakes and adoptions. It accepts and returns JSON, uses standard HTTP methods and status codes, and authenticates with API keys.

Base URL and versioning

All requests go to:

https://api.corgibase.example/v2

The version (v2) is part of the path. We add fields and endpoints to a version without notice, so your code should ignore fields it doesn't recognize. Breaking changes only ship in a new version, and old versions are supported for at least 12 months after a new one is released.

Live and sandbox data

Keys starting with cb_live_ act on your real shelter. Keys starting with cb_test_ act on a sandbox shelter with sample animals that you can change freely.

Tip:
Every account includes a sandbox shelter with sample animals. Use a sandbox key (prefix cb_test_) while you build and test your integration.

Plan requirements

The Rescue plan includes read-only API access. Shelter and Network plans include full read and write access.
