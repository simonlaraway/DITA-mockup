Subscribing to webhooks

Get notified when something changes in your shelter, instead of polling the API.

Before you begin

You need a key with the webhooks:manage scope and an HTTPS endpoint that can receive POST requests.

Procedure

  1. Create a subscription for the events you need. 
    curl -X POST "https://api.corgibase.example/v2/webhooks" \
  -H "Authorization: Bearer $CORGIBASE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.org/hooks/corgibase",
       "events": ["animal.status_changed", "adoption.finalized"]}'

    The response includes a signing_secret. Store it securely.

  2. In your endpoint, verify each delivery's signature.

    Compute an HMAC-SHA256 of the raw request body with your signing secret, and compare it with the CorgiBase-Signature header. Reject requests that don't match.

  3. Respond with any 2xx status within 10 seconds.

    Failed deliveries are retried with backoff for up to 24 hours. Use the event's id to ignore duplicates.

Results

Available events:

  • animal.created, animal.updated, animal.status_changed
  • adoption.application_received, adoption.approved, adoption.finalized
  • vaccination.due
