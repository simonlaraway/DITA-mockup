Creating an API key

Create a key to authenticate your API requests. Each key is limited to the scopes you choose.

Before you begin

Note:
Only users with the Shelter administrator or Owner role can do this.
Warning:
An API key has the same access as the user who created it. Store keys in a secrets manager, never in source code or client-side apps.

Procedure

  1. In CorgiBase, open Settings > API keys.
  2. Click Create key and give it a name that says where it's used, such as "Website listings".
  3. Choose Live or Sandbox.
  4. Select only the scopes the integration needs.
    ScopeAllows
    animals:readList and read animals, photos and statuses
    animals:writeCreate intakes and update animal profiles
    adoptions:readRead applications and adoptions (includes personal data)
    adoptions:writeSubmit applications from your own forms
    webhooks:manageCreate and delete webhook subscriptions
  5. Click Create and copy the key.

    The full key is shown only once. If you lose it, delete the key and create a new one.

Results

Send the key as a bearer token in the Authorization header of every request:

Authorization: Bearer cb_live_8f3k2Q...
