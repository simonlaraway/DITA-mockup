Installing Acme Widget

Install the Acme Widget agent on your workstation.

Before you begin

Warning:
Disconnect the Acme Widget from power before you open the housing.

Procedure

  1. Download the installer for version 3.2.
  2. Open AcmeWidget.dmg and drag the app to Applications.
  3. Run AcmeWidgetSetup.exe and follow the wizard.
  4. Run sudo dpkg -i acme-widget.deb.
  5. [Admin]Register the device with your fleet license key.

    Find the license key in the admin console under Billing.

  6. Restart the Acme Widget service.

Results

The Acme Widget icon appears in the menu bar.
