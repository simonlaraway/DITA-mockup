Shelter settings

Organization-wide settings in Settings > Shelter. Changes apply to every user immediately.

SettingDefaultDescription
Shelter name and logoFrom sign-upShown on listings, contracts and emails.
Time zoneFrom sign-upUsed for due dates, shifts and reports.
Stray hold period72 hoursHow long strays stay on hold before becoming available. Set this to match local law.
Animal ID prefixCB2–4 letters. Applies to new animals only.
Adoption fee defaultsNoneDefault fees by species and age group. Staff can override them per adoption.
Require two-step verificationOnRecommended. Turning it off requires the Owner role.
Session timeout12 hoursShorten this for shared front-desk computers.
Data retention for declined applications12 monthsPersonal data in declined applications is deleted after this period.
