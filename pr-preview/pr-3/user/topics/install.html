Installing Acme Widget

Install the Acme Widget agent on your workstation.

Before you begin

Warning:
Disconnect the Acme Widget from power and wait 30 seconds before you open the housing.

Procedure

  1. Download the installer for version 3.2 3.3.
  2. Open AcmeWidget.dmg and drag the app to Applications.
  3. Run AcmeWidgetSetup.exe and follow the wizard.
  4. Run sudo dpkg -i acme-widget.deb.
  5. Restart the Acme Widget service.

Results

The Acme Widget icon appears in the menu bar.
