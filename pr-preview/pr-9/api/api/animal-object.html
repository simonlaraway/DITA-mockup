The animal object

Fields returned for an animal by GET /animals and GET /animals/{id}.

FieldTypeDescription
idstringPermanent animal ID, for example CB-2026-00412.
namestringCurrent name.
speciesenumdog, cat, rabbit or other.
breedsstring[]Primary breed first. Empty for unknown.
birth_date_estimatedateISO 8601 date.
sizeenumxs through xl.
statusenumCurrent status, for example available or adoption_pending.
kennel_idstring | nullCurrent kennel. null if in foster or adopted.
public_descriptionstringListing text, as Markdown.
primary_photo_urlstring | nullURL of the first photo. URLs are signed and expire after 24 hours.
updated_atdatetimeISO 8601 timestamp of the last change.
