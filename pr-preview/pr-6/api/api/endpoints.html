Endpoints

All endpoints in API v2. Paths are relative to https://api.corgibase.example/v2.

MethodPathScopeDescription
GET/animalsanimals:readList animals. Filter by species, status, site.
GET/animals/{id}animals:readGet one animal.
PATCH/animals/{id}animals:writeUpdate profile fields.
GET/animals/{id}/photosanimals:readList photo URLs in display order.
POST/intakesanimals:writeRecord an intake and create the animal.
GET/kennelsanimals:readList kennels and their occupants.
GET/adoptionsadoptions:readList applications and adoptions.
POST/adoptionsadoptions:writeSubmit an application.
GET/webhookswebhooks:manageList webhook subscriptions.
POST/webhookswebhooks:manageCreate a subscription.
DELETE/webhooks/{id}webhooks:manageDelete a subscription.
