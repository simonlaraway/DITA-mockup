Making your first request

List the adoptable dogs in your sandbox shelter, then fetch one of them.

Before you begin

You need a sandbox key with the animals:read scope, and curl or any HTTP client.

Procedure

  1. Store your key in an environment variable. 
    export CORGIBASE_KEY="cb_test_..."
  2. List available dogs. 
    curl "https://api.corgibase.example/v2/animals?species=dog&status=available&limit=2" \
  -H "Authorization: Bearer $CORGIBASE_KEY"

    The response contains a page of animals and a cursor for the next page:

    {
  "data": [
    { "id": "CB-2026-00412", "name": "Biscuit", "species": "dog", "status": "available", ... },
    { "id": "CB-2026-00398", "name": "Waffles", "species": "dog", "status": "available", ... }
  ],
  "next_cursor": "eyJpZCI6IkNCLTIwMjYtMDAzOTgifQ"
}
  3. Fetch one animal by ID. 
    curl "https://api.corgibase.example/v2/animals/CB-2026-00412" \
  -H "Authorization: Bearer $CORGIBASE_KEY"

Results

You've authenticated and read data from the API. Next, learn how to page through large result sets, or subscribe to webhooks so you don't need to poll.
